retrospective development, not new prospective confirmation. No new traffic,

Freeze this specification and sources before computing the new diagnostics.

Question: do calibration agreement, deadline-local CDF sensitivity or a
warmup-implied location shift warn about larger multi-deadline transfer errors
at the existing acquisition cost, compared with ordinary warmup-CDF disagreement?
This revisits ordinary timing checks across a panel after their earlier
single-deadline screens; it does not introduce a novel state measurement.

Retain all 78 NGINX validation cohorts: original 18, power confirmation 24,
rate-transfer 12 and fresh deadline-panel 24. Preserve five quantile labels at

Fixed exploratory diagnostics, with no threshold search:

1. Maximum calibration-cohort deviation from the panel-basis pooled forecast,
   over all five cutoffs. A <=5 pp value accepts the unchanged reference forecast.
   This is constant within the reference group, not a within-group selector.
2. Maximum one-sided reference miss-probability change over the five cutoffs
   for a fixed +/-100 microsecond deadline shift. <=5 pp accepts reference.
   This is a sensitivity stress, not a justified bound on future timing drift.
3. Warmup-CDF disagreement: maximum absolute warmup/reference miss-probability
   difference across the panel. <=5 pp accepts reference. This is the ordinary
   equal-acquisition warning comparator.
4. Warmup-implied location change: delta = median(25 warmup) - median(reference).
   Evaluate reference miss probability at D-delta. Maximum absolute change from
   the unchanged reference prediction <=5 pp accepts reference. Also report
   the conjunction with calibration agreement, without choosing a winner.
   Medians retain exact half-nanosecond arithmetic. If reference or warmup has
   failures, location quantities are unavailable and their flags refuse.

Ordinary forecast controls are reference CDF, 25-offer warmup CDF,
count-weighted reference-plus-warmup CDF, and location-shifted reference CDF.

Failures remain mass at infinity and miss every finite cutoff. No success-only
