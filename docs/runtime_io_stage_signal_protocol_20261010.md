# Response-stage transfer signal: bounded development screen

10 October 2026. All historical outcomes are already known. This protocol fixes
one additional feature family before calculating its new scores. It is a
discovery screen, not prospective registration or independent validation.

Question: does separating client dispatch lag, dispatch-to-headers time and
headers-to-body-completion time reveal changes hidden by complete-response
agreement? Opposing stage changes can conceal a change in the total. Whether
that change predicts subsequent transfer failure is an unestablished hypothesis.
These client intervals do not isolate server CPU, queueing or physical frequency.

Use all 54 completed NGINX validation cohorts from the original, power-confirmation
and rate-transfer campaigns. Keep the original deadline, 20.565395 ms, all-offer
failure accounting and calibration references: all original calibration; assigned
policy calibration for power; ordinary fixed-5/s calibration for rate. Retain
throttling observations and all adverse cases. The interrupted power pilot is a
different, incomplete design and is not another completed campaign.

Decision: after the existing 25 warmup offers and drain, before the measured
300-offer window. This new guard was not executed historically. Original NGINX
has synchronous acquisition order in preserved source but lacks a separate
warmup-to-measurement monotonic stamp; the newer campaigns preserve that stamp
and an ordinary warmup forecast barrier. Only calibration and warmup data
may produce scores. Read future outcomes only after every score is finalized.
No extra prefix length, cutoff, deadline, blend or feature search follows.

For each client stage j, delta_j is median(warmup stage j) minus median(reference
stage j). Map it to the unchanged reference complete-response CDF:
q_j = 100 |p_ref(D-delta_j)-p_ref(D)|. The chronological term uses the difference
between analogous CDF projections from the first and last twelve warmup offers;
the middle offer is unused for that term. The stage score is the maximum of all
three stage shifts and their chronological terms. Accept the original forecast
only when this score is <=5 pp and all reference/warmup offers succeeded.
This is an ordinary stage-conditioned discrepancy heuristic, not a new predictor
or risk certificate. Its counterfactual additive-shift mapping is an assumption.

Equal-information ordinary comparators receive the identical reference, complete
client milestones, 25 warmup offers and decision time: always answer, deadline
miss-fraction disagreement, complete-response median-shift plus chronological
shift (the previous timing rule), and full-response ECDF sup distance. Also report
maximum stage ECDF distance as a direct distribution check. The same descriptive
5 pp cutoff is retained; an ECDF cutoff is not a calibrated statistical test.
All guards assess the same original forecast on their accepted subsets.

Report coverage, incorrect assurances (accepted absolute future error >5 pp),
false warnings, maximum accepted error and transition-region coverage. The
existing usefulness screen requires >=50% coverage overall and in the observed
10–90% miss region, no accepted error >5 pp in each campaign and separately P0
power. Future miss fractions define evaluation subgroups only. Scores are also
reported for the known original excursion and power cohort 23; these examples
were selected before new scoring because prior screens identified them.

Cost: no extra saved-data acquisition; all methods consume the same 25 probes
and full acquired calibration. This does not prove deployment overhead savings.
All three client stages were recorded already. Source acquisition and monotonic
barriers must be checked; warmup client output includes completed integrity checks.
There are only three campaign histories on one host with shared references.

Stop after this screen. If it fails, retain that result rather than choosing a
more favorable threshold. No traffic, host-policy changes, perf/BPF observer,
new collector, manuscript revision or confirmation experiment is authorized by
this offline assessment. New sensing requires a separately concrete proposal.
