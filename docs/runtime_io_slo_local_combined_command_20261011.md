# One command for the local supplement

The combined wrapper uses the already sealed supplement-03 package. It changes
no scientific plan, package seal, old evidence, allocation or campaign cap. It
forwards explicit amendment acceptance and native allocation confirmation to
both existing launchers.

Save work before this external command; the per-service launchers close the
named background apps.

```bash
bash /home/Aditya/Desktop/Research_project/cpu-quota-tail-latency/diagnostic/start_slo_local_supplement_all.sh \
  --amendment-accepted --allocation-confirmed
```

Order is fresh setup once, Go, then NGINX without repeating setup. The wrapper
stops on any error and preserves the attempted state. It does not automatically
retry, resume a failed setup or proceed after a failed Go command. If it stops,
retain the terminal output for review before a separate next action. Repeating
the wrapper refuses an already attempted setup/campaign through the existing
package guards.

The flags accept the separate 36-slot local supplement and its additional
15,300 s (4 h 15 min) campaign cap, and confirm the declared AMD host allocation.
External runtime qualification is still performed during execution. Passing
offline checks does not establish qualification, novelty or independent validity.
